题目描述:

- 系统中有多个生产者和消费者, 共享一个可以存放1000件产品的**环形**缓冲区(初始为空).

- 缓冲区未满,生产者可以进入缓冲区放一个产品, 否则等待.
- 缓冲区未空, 消费者可以进入缓冲区取走一件产品, 否则等待
- 只有消费者从缓冲区连续取走10件产品后, 才允许其它消费者进入缓冲区取走产品.





信号量设置:

- 设置信号量empty表示空闲缓冲区的数量, 初始值为1000.

- 设置信号量count为计数器，用于记录缓冲区中产品的数量, 初始值为0. 当count>=10时,才允许消费者进入缓冲区.

- 设置互斥信号量mutex, 用于控制生产者和消费者对缓冲区的互斥访问.

```cpp
semaphore empty = 1000;
int count = 0;
semaphore mutex = 1;

producer()
{
    while(1)
    {
    	P(empty);
        P(mutex);
    }
}



consumer()
{
    while(1)
    {
        
    }
}
```
